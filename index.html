About Me

Hello! I'm Ramakrishnan Sivakumar.

  • Principal Engineer @ AMD
  • On-device AI
  • Lemonade maintainer
I'm Ramakrishnan Sivakumar, a machine learning software engineer with over a decade of experience. My focus right now is on-device AI — getting large language models to run efficiently on consumer hardware — and I'm a maintainer of Lemonade, an open-source SDK for running LLMs locally. Across roles at Intel, Groq, and now AMD, I've shipped ML compilers, accelerator software, and developer tools that make AI faster on the hardware it runs on.
